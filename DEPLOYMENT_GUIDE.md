# 🚀 Руководство по развертыванию на Railway

## Быстрый старт (5 минут)

### 1️⃣ Подготовка Telegram бота

1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Создайте нового бота: `/newbot`
3. Скопируйте токен (выглядит как `123456:ABC-DEF1234ghIkl...`)
4. Отключите приватность: `/setprivacy` → Disable
5. Добавьте бота администратором в ваш канал

### 2️⃣ Получение ID канала

Два способа:

**Способ 1 (простой):**
1. Перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)
2. Скопируйте `Forwarded from chat: -1001234567890`

**Способ 2 (через браузер):**
1. Откройте канал в Telegram Web
2. ID будет в URL: `https://web.telegram.org/z/#-1001234567890`

### 3️⃣ Получение вашего Telegram ID

1. Напишите боту [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ваш ID: `Id: 123456789`

### 4️⃣ Деплой на Railway

#### Шаг 1: Создание проекта
1. Зайдите на [Railway.app](https://railway.app)
2. Войдите через GitHub
3. Нажмите **"New Project"**
4. Выберите **"Deploy from GitHub repo"**
5. Выберите репозиторий `Travel-agent-lead`
6. Railway автоматически обнаружит Dockerfile и начнет деплой

#### Шаг 2: Добавление PostgreSQL
1. В проекте нажмите **"New"** → **"Database"** → **"Add PostgreSQL"**
2. Railway автоматически создаст переменную `DATABASE_URL`
3. Подождите пока БД развернется (~30 секунд)

#### Шаг 3: Настройка переменных окружения
1. Перейдите в раздел **"Variables"**
2. Добавьте следующие переменные:

```
BOT_TOKEN=<ваш_токен_от_BotFather>
CHANNEL_ID=<ID_канала_с_минусом>
ADMIN_ID=<ваш_Telegram_ID>
BOT_MODE=webhook
WEBHOOK_URL=https://<ваш-проект>.up.railway.app
```

**Пример:**
```
BOT_TOKEN=6123456789:AAEhBOweik6ad3C_3kKk-KKwE2XL3s
CHANNEL_ID=-1001234567890
ADMIN_ID=123456789
BOT_MODE=webhook
WEBHOOK_URL=https://telegram-lead-bot-production.up.railway.app
```

#### Шаг 4: Получение WEBHOOK_URL
1. После первого деплоя Railway предоставит домен
2. Найдите его в разделе **"Settings"** → **"Domains"**
3. Скопируйте URL (например: `telegram-lead-bot-production.up.railway.app`)
4. Добавьте `https://` в начало
5. Обновите переменную `WEBHOOK_URL`

#### Шаг 5: Перезапуск
1. После добавления всех переменных нажмите **"Deploy"**
2. Или Railway автоматически перезапустит бота

### 5️⃣ Проверка работоспособности

1. **Health Check:**
   - Откройте `https://ваш-домен.up.railway.app/health`
   - Должно быть: `{"status": "healthy", "database": "connected", ...}`

2. **Логи:**
   - Перейдите в **"Deployments"** → **"View Logs"**
   - Должно быть: `Бот запущен: @ваш_бот`

3. **Тест бота:**
   - Напишите `/start` вашему боту в личку
   - Бот должен ответить меню администратора

### 6️⃣ Добавление первого агента

1. Напишите боту: `/add_agent @username "Имя Фамилия"`
   - Пример: `/add_agent @john_doe "Джон Доу"`

2. Агент должен написать `/start` боту для активации

3. Проверьте список: `/agents`

### 7️⃣ Проверка распределения

1. Напишите комментарий в канале с ключевым словом (например: `+` или `хочу тур`)
2. Агент должен получить уведомление в личку
3. Проверьте статистику: `/stats`

## 🔧 Опциональные настройки

### Redis (для кеширования)
```
1. New → Database → Add Redis
2. Railway автоматически добавит REDIS_URL
```

### Sentry (мониторинг ошибок)
```
1. Создайте проект на sentry.io
2. Скопируйте DSN
3. Добавьте переменную: SENTRY_DSN=https://...
```

### Дополнительные переменные
```
LOG_LEVEL=INFO              # DEBUG, INFO, WARNING, ERROR
TIMEZONE=Asia/Tashkent      # Ваш часовой пояс
MAX_AGENTS=20               # Максимум агентов
```

## 🐛 Решение проблем

### ❌ "Бот не отвечает"
**Проблема:** Неверный токен или бот не запущен

**Решение:**
1. Проверьте токен: Variables → BOT_TOKEN
2. Проверьте логи: Deployments → View Logs
3. Перезапустите: Settings → Restart

### ❌ "Database connection error"
**Проблема:** БД не подключена

**Решение:**
1. Убедитесь что PostgreSQL добавлен
2. Проверьте переменную DATABASE_URL
3. Подождите 1-2 минуты после добавления БД

### ❌ "Webhook не работает"
**Проблема:** Неверный WEBHOOK_URL

**Решение:**
1. Проверьте формат: `https://домен.up.railway.app` (без `/` в конце)
2. Убедитесь что BOT_MODE=webhook
3. Перезапустите бота

### ❌ "Не приходят уведомления"
**Проблема:** Агент не активирован или на паузе

**Решение:**
1. Агент должен написать `/start` боту
2. Проверьте статус: `/agents`
3. Если на паузе: `/resume_agent @username`

### ❌ "Не распределяются лиды"
**Проблема:** Бот не админ канала или неверный CHANNEL_ID

**Решение:**
1. Добавьте бота админом в канал
2. Проверьте CHANNEL_ID (должен начинаться с `-100`)
3. Проверьте что есть активные агенты: `/agents`
